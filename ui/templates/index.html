Define packages & file slots

Each package (e.g. mlb) maps slot ids to the filename used under inputs/ when you upload. Slot ids should match your input profiles (e.g. event_source, metric_source). You can use any .xlsx basename per slot; common slot names like schedule or stats are auto-mapped to roles when inputs.file_roles omits that package, or use event_source + metric_source for zero-config schedule+stats packages.
